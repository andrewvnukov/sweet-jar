# Сладкая Банка / Sweet Jar

Merge-physics в духе Suika Game под Яндекс Игры. Один статический
`index.html` (canvas + HUD + физика + вся логика), процедурный звук в
`sfx.js`, без бандлера и внешних зависимостей.

Петля: прицелиться → бросить конфету → слияние двух одинаковых в десерт
покрупнее → монеты → апгрейды. Банка переполнилась — забег окончен,
монеты остаются, прогресс — нет.

Правила, по которым игра держит игрока — видимая цель на длинной дистанции —
лежат в [`docs/playermotivation.md`](docs/playermotivation.md). Читать до того,
как менять прогрессию или добавлять цели.

## Экономика

| Что | Как устроено |
| --- | --- |
| Десерты | 10 тиров, ценность ×2 за тир (2 → 1024 монеты за слияние); два верхних открывает последняя остановка маршрута |
| Апгрейды | щедрая рука (макс. 2), глазок (макс. 10), вежливая банка (макс. 10), сахарная глазурь (×1,12 за уровень, макс. 40) |
| Множитель | `costMul/k = 1,35/1,12 ≈ 1,2` за уровень глазури — окупаемость растёт плавно |
| Конец забега | награда за забег зависит от достигнутого тира, а не от скорости провала |

Два правила, на которых держится баланс:

- **`earn` против `grant`.** Слияния идут в `S.lifetimeEarned` (метрика
  прогресса), подарки за рекламу, ежедневка и награды за задания — нет.
- **Округление только при показе.** Начисления остаются точными.

## Удержание и реклама

- **Маршрут «От подоконника до королевского приёма»** — дальний горизонт
  игры, который сшивает отдельные забеги в один длинный путь: шесть
  остановок (кухонный подоконник → лоток на ярмарке → своя лавка → кафе →
  кондитерская фабрика → королевский приём). Каждая меняет палитру сцены и
  добавляет ровно одно новое правило: заказы (названный десерт платит
  вдвое), витрина (готовый десерт можно продать и освободить банку), гости
  (сами забирают крупные десерты), конвейер (конфеты падают сами, игрок
  целится), и наконец два новых верхних десерта. Следующая остановка
  открывается чек-листом из трёх разнотипных пунктов (собрать / достичь /
  сделать). Переезд **ничего не отнимает** и даёт постоянную прибавку к
  монетам за слияния. Шестая — псевдофинал: экран «ты дошёл» и второй круг
  с выросшими требованиями. Карта с туманом открывается нажатием на полосу
  маршрута. Награда за переезд — `grant`; старым сейвам остановка выводится
  из достигнутого тира, без выплат за прошлое.
- **Ежедневная серия** — цикл из 7 дней по строке даты (`YYYY-MM-DD`),
  награда привязана к темпу игрока, кнопка «Забрать ×2» за ролик.
- **Rewarded-слоты**: подарок (КД 90 с), убрать 3 конфеты (КД 3 мин), особая
  конфета (КД 2 мин), «Продолжить» на экране конца забега, награда за ярлык.
- **Межстраничная** — только между забегами, с прогревом сессии 90 с и
  паузой, отсчитываемой от факта показа (`wasShown`).
- **Контекстные подсказки** — триггеры условные, одна за раз, один раз
  навсегда; никогда поверх открытой модалки.

## Требования площадки

`LoadingAPI.ready()` уходит ровно один раз и до того, как игра доступна;
язык платформы читается на каждом запуске до первой отрисовки и нигде не
сохраняется; звук глушится и на время рекламы, и при уходе вкладки в фон;
сейв дожимается с `flush` на `visibilitychange`/`pagehide` с собственным
троттлом 3 с; лидерборд пишется через `setScore` (с фолбэком на устаревший
`setLeaderboardScore`) только для авторизованного игрока и не чаще раза в
секунду; повреждённый или чужой сейв не роняет запуск (неизвестный тир
выбрасывается, а не подрезается к максимуму).

## Тест

```
npm install
node test/smoke.mjs
```

Playwright-тест поднимает игру с моком Yandex SDK (подменяется через
`addInitScript` до загрузки скриптов) и проверяет физику и слияния,
экономику, все rewarded-слоты, конец забега, ежедневку, задания, миграцию
и повреждённые сейвы, подсказки, GameReady и вёрстку на узких экранах.
Если в окружении лежит заранее скачанный Chromium другой сборки, путь к
нему передаётся через `PW_CHROMIUM`.

## Сборка билда

`index.html` должен лежать в корне zip. Внешние ресурсы — только шрифты
Google Fonts и `yandex.ru/games/sdk/v2`.
